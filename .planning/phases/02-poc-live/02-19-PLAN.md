`restart boundary` 是 paired server B2 workflow 持久化的单调 generation/fence 转换，不是按钮时间、PID变化、lease expiry或进程消失猜测。边界建立后必须按顺序：停止接受旧 Worker 新 claim → 在每次 adapter request 前以 `assertCurrent` 拒绝 old generation/fence → 在 observation/ledger/job commit 前再次拒绝 old generation/fence → only-owned supervisor 以 installation id+nonce+PID+OS start identity+exact executable+authenticated control 确认旧 Worker actual exit → 启动并认证同 build 的新 Worker/current generation → `recoverExpired` 只恢复仍有效 durable attempts，不重置 0/5s/30s预算、不重开/接管 Profile → 新 Worker执行 current B2 probes。unknown/mismatch/timeout 保持 human_needed；不 broad kill、不删锁、不因 lease 过期 release Profile。
