来自 02-08：
```typescript
export interface ProtectedAuthStatusProjection { /* paired local_ui only */ }
export interface RedactedAuthStatusProjection { /* CLI/MCP only; UI 不把它升级为 protected */ }
export interface RedactedEvidenceReceipt { /* 无姓名、邮箱、课程名、Profile、页面或网络资料 */ }
export interface SafeAuthApiError {
  code: string;
  stage: 'auth_api';
  nextAction: string;
}
export interface AuthActionAccepted {
  accepted: true;
  actionReceiptId: string;
  resultCode: string;
}

export function presentProtectedAuthStatus(/* paired principal + stores */): ProtectedAuthStatusProjection;
export function presentRedactedAuthStatus(/* CLI/MCP */): RedactedAuthStatusProjection;
export function presentEvidenceReceipts(/* exact EvidenceCellKey */): RedactedEvidenceReceipt[];
```

固定 API：
```text
GET  /api/auth/status
GET  /api/auth/receipts?{strict EvidenceCellKey}
POST /api/auth/configuration/confirm  { config: ApprovedSourceConfig }
POST /api/auth/login/open            { source: SourceId, approvedConfigId: string }
POST /api/auth/probe                 strict SourceProbeRequest command；
                                      login_completed 另带 server-issued actionReceiptId
POST /api/auth/logout-intent         { source: SourceId, acknowledged: true }
POST /api/auth/binding/confirm       { candidateBindingId: uuid, decision: 'confirm'|'reject' }
```

`POST /api/auth/login/open` 只有在 paired session+CSRF 成功后才返回 server-issued、一次性、绑定 session/source/config/generation/kind 的 `AuthActionAccepted`；浏览器不得生成 actionReceiptId。`ProtectedAuthStatusProjection.nextAction` 可提供 `{kind:'confirm_binding',candidateBindingId}`；binding mutation 只提交 opaque candidate id 与决定，human-action provenance 由服务端从 paired mutation 建立。UI 不存在任何 UAT/live receipt 写 route，GET receipts 只读。

所有 mutation 只接受现有 `autoed_session` HttpOnly/SameSite=Strict cookie、exact same-origin 与 `x-autoed-csrf`；Bearer CLI/MCP 即使携带 CSRF 也为 403。public/pending 请求 auth status 为 401。错误只接受 02-08 `SafeAuthApiErrorSchema` 的 `{code,stage,nextAction}`，UI 不渲染 exception message/cause/stack/path/page/identity。
