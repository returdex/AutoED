```typescript
export class FileProfileOwnershipCoordinator implements ProfileOwnershipCoordinator {
  reserve(input: { installationId: string; browserBuildId: string; generation: number; fence: number }): Promise<ProfileOwnership>;
  attach(reservation: ProfileReservation, process: {
```

`inspect` 的平台语义固定为：exact OS+authenticated-control running→`PROFILE_IN_USE/human_needed`；OS unknown、PID reuse、identity/control mismatch→`PROFILE_OWNERSHIP_UNCONFIRMED/human_needed`；只有 OS 确认 PID 不存在→`PROFILE_EXITED/proceed`，其后才允许 release。lease 只 fencing。
