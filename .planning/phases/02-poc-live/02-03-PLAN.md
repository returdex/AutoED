来自 `packages/domain/src/model.ts`（由 02-01 创建）：
```typescript
export interface ProfileReservation {
  installationId: string;
  browserBuildId: string;
  nonce: string;
  generation: number;
  fence: number;
  reservedAt: string;
}
export interface ProfileOwnerIdentity extends ProfileReservation {
  pid: number;
  osStartIdentity: string;
  executable: string;
  startedAt: string;
}
export type ProfileOwnershipState =
  | 'available' | 'reserved' | 'owned'
  | 'profile_in_use' | 'ownership_unconfirmed' | 'confirmed_exited';
export interface ProfileOwnership {
  state: ProfileOwnershipState;
  disposition: 'proceed' | 'human_needed';
  resultCode:
    | 'PROFILE_AVAILABLE' | 'PROFILE_RESERVED' | 'PROFILE_OWNED'
    | 'PROFILE_IN_USE' | 'PROFILE_OWNERSHIP_UNCONFIRMED' | 'PROFILE_EXITED';
  reservation: ProfileReservation | null;
  owner: ProfileOwnerIdentity | null;
}
```

来自 `packages/application/src/ports.ts`（由 02-01 创建）：
```typescript
export interface ProfileOwnershipCoordinator {
  reserve(input: {
    installationId: string;
    browserBuildId: string;
    generation: number;
    fence: number;
  }): Promise<ProfileOwnership>;
  attach(
    reservation: ProfileReservation,
    process: { pid: number; osStartIdentity: string; executable: string; startedAt: string }
  ): Promise<ProfileOwnership>;
  inspect(owner: ProfileOwnerIdentity): Promise<ProfileOwnership>;
  release(owner: ProfileOwnerIdentity): Promise<void>;
}
```

## 信任边界

| 边界 | 不可信输入/风险 | 强制控制 |
|---|---|---|
| application → platform coordinator | generation/fence、安装/构建身份及并发调用可能过期、伪造或竞态 | 02-01 strict schema、安装元数据复核、原子 reservation、nonce 与 fence 比较 |
| coordinator → 仓库外 Profile/runtime record | 路径逃逸、symlink/junction、云同步位置、权限降级、敏感 Profile 泄漏 | 只使用 `managedPaths`、safe ancestor/excluded root/local volume、OS protected path、无路径输出 |
| durable record → OS PID | PID 重用、记录篡改、仅凭 PID/进程名误认归属 | installation id + nonce + PID + OS start identity + canonical exact executable 全量匹配 |
| coordinator → authenticated control | 伪造 responder、proof 重放、错误端口/持有者冒充 | 固定 inspect challenge、安装级秘密、challenge/完整 owner/fence 绑定、时序安全比较、有界 timeout |
| lease/fence → cleanup | lease 到期被误当成退出并删除仍在使用的锁 | lease 仅 fencing；仅 OS confirmed-exited 允许清 owner record；unknown/running 硬停 human_needed |
