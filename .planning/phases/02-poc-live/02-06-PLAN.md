export type SourceId = 'moodle' | 'edstem';

  | 'moodle.auth_probe'

  probe(request: SourceProbeRequest, signal: AbortSignal): Promise<SourceProbeResult>;

来自 02-05 的 `packages/platform/src/browser.ts`：
```typescript
export interface LocalPlaywrightBrowserProvider {
  openBackground(input: BrowserOpenInput, guard: BrowserOperationGuard): Promise<BrowserProbeSession>;
  openOfficialLogin(input: BrowserOpenInput, guard: BrowserOperationGuard): Promise<BrowserProbeSession>;
  close(owner: ProfileOwnerIdentity, guard: BrowserOperationGuard): Promise<void>;
}

export interface BrowserProbeSession {
  navigate(target: URL, guard: BrowserOperationGuard): Promise<NavigationObservation>;
  waitFor(locator: LocatorSpec, guard: BrowserOperationGuard): Promise<void>;
  readVisible(locator: LocatorSpec, guard: BrowserOperationGuard): Promise<string | null>;
  readAttribute(locator: LocatorSpec, name: string, guard: BrowserOperationGuard): Promise<string | null>;
  close(guard: BrowserOperationGuard): Promise<void>;
}

export interface NavigationObservation {
  redirectOrigins: readonly string[];
  finalOrigin: string;
}
```

02-05 的 background guard 在每个方法前后检查 AbortSignal、maintenance generation、ProfileOwnerIdentity/fence；popup/交互、download、非 GET/HEAD、越界 origin、abort/fence 分别以严格 safe code 失败。`NavigationObservation` 和 `LocatorSpec` 仅存在于 platform 内部，不进入 application/API/MCP；adapter 内 locator 必须是静态、版本化、长度有界的常量，不接受运行时 selector。

## 信任边界

|---|---|---|
| application request → sealed adapter | source/action/config/scope 引用可能错配或携带额外浏览器参数 | 02-01 strict discriminated schema、四动作穷尽映射、配置/范围引用逐值核对、browser-before-admission 调用计数 |
| approved config → URL/locator construction | 配置可能陈旧、来源不匹配或被当作任意导航模板 | 仅规范化 official origin + 内部固定 suffix/locator registry；调用方不得提供 URL/path/query/selector |
| BrowserProbeSession → untrusted source page | redirect、popup、download、表单/POST、脚本、隐藏 DOM、parser drift | 02-05 guard + adapter 逐跳 origin 防御；background 非 GET/HEAD 和交互全部阻断；静态 locator、有界可见读取、无 evaluate/API fallback |
| source identity evidence → later binding | 页面可伪造显示名/邮箱或省略稳定主体/组织 | 来源专属 positive marker；stable subject+organization+scope 分开返回；adapter 不做 confirmed binding；不足时 human_needed |
| synthetic fixture → evidence ledger | fixture 可能误接外网或被标成 live | route deny-all/closed proxy、请求计数、synthetic producer 固定 S/I、无 L writer authority |
